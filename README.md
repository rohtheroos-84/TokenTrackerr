## About the Project

TokenTrackerr is a front-end web development project created to demonstrate modern web design principles, responsive layouts, and interactive user interfaces. It mimics the functionality of a cryptocurrency tracking platform but uses only static data.

### Project Purpose
- Educational demonstration of HTML, CSS, and JavaScript
- Showcase of responsive web design techniques
- Practice with modern UI/UX patterns
- Portfolio project for web development skills

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/rohtheroos-84/TokenTrackerr.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd TokenTrackerr
   ```

3. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local development server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js http-server
     npx http-server
     ```

4. **Access the application**
   - Direct file: Open `index.html`
   - Local server: Navigate to `http://localhost:8000`
